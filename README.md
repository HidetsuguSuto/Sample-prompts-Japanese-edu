# Sample-prompts-Japanese-edu
2026年度台湾日本語文学会国際学術シンポジウムの基調講演『生成AI利活用の指針と「AIハッカソン」を通じた実践的取り組み』で紹介した日本語初級壁打ち学習用プロンプト例

## 概要

日本語初学者向けに、教科書の語彙・文法に沿った**穴埋め5択クイズ（全10問）**を出題し、採点・解説・ヒントを返してくれる「AI先生」を作るためのプロンプトです。

主な特徴：

- 1問ずつ出題し、学習者の回答を待ってから次に進む
- 正解が必ず1つに定まるよう、出題前に「一意性チェック」「意味役割チェック」を行う
- 不正解の場合は、正解の解説に加えて、選んだ選択肢の正しい使い方も説明する
- 「ヒント」と入力すると、語彙のヒント → 文法のヒントの順に1つずつ提示する
- 10問終了後に合計点（10点満点）と励ましの総評を表示する

## ファイル構成

| ファイル | 内容 |
|----------|------|
| [`japanese_learning_quiz_prompt.md`](japanese_learning_quiz_prompt.md) | 見出しや表で整形した版。出題前の一意性チェックの結果（`✅ チェック完了：…`）を問題の直前に表示します。 |
| [`japanese_learning_quiz_prompt_plain.txt`](japanese_learning_quiz_prompt_plain.txt) | プレーンテキスト版。一意性チェックは内部でのみ行い、学習者には表示しません。 |

授業の様子を見ながら AI の判断過程を確認したい場合は整形版、学習者に問題だけを見せたい場合はプレーンテキスト版がおすすめです。

## 使い方

### 1. 「テキスト」セクションを書き換える

プロンプト末尾の **「テキスト」** セクションには、サンプルとしてレッスン1〜3のスキット・新しいことば・文法が入っています。授業で使う教科書に合わせて、次の形式で書き換えてください。

```
* レッスン1
  * スキット
    （会話文）
  * 新しいことば
    語彙1／語彙2／語彙3 …
  * 文法
    （文型）
```

クイズはこのセクションに書かれた語彙・文法からのみ出題され、解説で使う漢字もここに出てくるものに限定されます。

### 2. カスタムGPTを作成する（ChatGPTの場合）

1. ChatGPT にログインし、「GPT」→「作成する」を開く
2. 「構成（Configure）」タブを選ぶ
3. 名前（例：日本語クイズ先生）と説明を入力する
4. 書き換えたプロンプトの全文を **「指示（Instructions）」** 欄に貼り付ける
5. 会話のきっかけ（Conversation starters）に `start` を登録しておくと便利です
6. 右上の「作成」から公開範囲（自分のみ／リンクを知っている人）を選んで保存する

同じプロンプトは、Gemini の Gem や Claude のプロジェクトなど、システムプロンプト（カスタム指示）を設定できる他のサービスでも利用できます。ただし、動作確認は ChatGPT（GPT-4o）で行っています。一意性チェックの結果表示（`✅ チェック完了：…`）の有無や形式などは、モデルによって異なる場合があります。

### 3. 学習者の操作

| 入力 | 動作 |
|------|------|
| `start` | 第1問から開始（途中でも最初からやり直し） |
| `1`〜`5` | 選択肢の番号で回答 |
| `ヒント` | ヒントを1つずつ表示（文法のヒントは最後） |

10問すべて回答すると、合計点と総評が表示されます。

## 注意事項

- 生成AIの出力には誤りが含まれる可能性があります。授業で使用する前に、教員が実際に何度か試して問題の質を確認してください。
- 曖昧な問題（正解が複数ありうる問題）が出た場合、プロンプトの指示により AI は謝罪して問題を差し替えますが、完全には防げません。
- 教科書の本文を「テキスト」セクションに記載する際は、著作権に配慮し、公開範囲を適切に設定してください。
